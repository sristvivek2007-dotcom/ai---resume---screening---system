# Netlify Deployment Checklist

- [ ] Extract the ZIP
- [ ] Upload all files to a GitHub repository
- [ ] Confirm `netlify.toml`, `package.json`, `public/`, and `netlify/functions/` are present
- [ ] Import repository in Netlify
- [ ] Confirm publish directory is `public`
- [ ] Deploy and wait for function bundling
- [ ] Test PDF upload
- [ ] Test DOCX upload
- [ ] Test CSV download
- [ ] Check the public URL on mobile
- [ ] Do not upload real resumes to a public repository
